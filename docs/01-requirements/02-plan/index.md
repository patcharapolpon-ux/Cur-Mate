# 02 - Plan

เก็บเอกสาร **แผนการดำเนินงาน** ที่แปลงมาจากข้อกำหนดใน [[../01-spec/index|01-spec]] เช่น

- Roadmap / timeline ของโปรเจกต์
- การแบ่ง phase หรือ milestone
- ลำดับความสำคัญ (priority) ของแต่ละฟีเจอร์
- ทรัพยากรและระยะเวลาที่คาดว่าจะใช้

แผนในโฟลเดอร์นี้จะถูกแตกย่อยต่อเป็นงานที่ลงมือทำได้จริงใน [[../03-task/index|03-task]]

นอกจากนี้ยังมี [[feature-list|feature-list]] — รายการฟีเจอร์ทั้งหมดพร้อมลำดับความสำคัญแบบ MoSCoW ดูแลโดย skill `feature-journey-sync`
