# Task Breakdown: Phase 1 - MVP: แกนหลักที่ใช้งานได้ครบวงจร

**Phase อ้างอิง**: [[../02-plan/release-plan|release-plan]] (Phase 1)
**เป้าหมายของ Phase**: ให้ระบบใช้งานได้ครบ flow จริงตั้งแต่ต้นจนจบ — แอดมินสร้างฐานความรู้เกณฑ์มาตรฐานและอนุมัติกฎเกณฑ์จนมีชุดเกณฑ์ active อย่างน้อย 1 ชุด → ผู้จัดทำหลักสูตรอัปโหลดเอกสาร มคอ.2 → ยืนยันข้อมูลรายวิชาที่สกัดได้ → เลือกชุดเกณฑ์ → เริ่มตรวจสอบความสอดคล้องภายในเล่มเดียวกัน → ดูรายงานผล
**Feature ที่เกี่ยวข้อง**: [[../02-plan/feature-list|feature-list]] (01, 02, 03, 05, 06, 07)

> **หมายเหตุลำดับการลงมือทำ**: ตารางด้านล่างเรียงงานตามลำดับที่ต้องลงมือทำจริง (ไม่ใช่เรียงตามเลขฟีเจอร์) คือ ฟีเจอร์ 06 → 07 ก่อน แล้วตามด้วย 01 → 02 → 03 → 05 เนื่องจาก flow การตรวจสอบต้องมีชุดเกณฑ์สถานะ active อย่างน้อย 1 ชุดก่อนเสมอ (อ้างอิงเหตุผลเดียวกับที่ระบุไว้ใน [[../02-plan/release-plan|release-plan]] หัวข้อ Dependency ของ Phase 1)
