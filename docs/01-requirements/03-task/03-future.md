# Task Breakdown: Phase 3 - Future: ช่องทางเสริม

**Phase อ้างอิง**: [[../02-plan/release-plan|release-plan]] (Phase 3)
**เป้าหมายของ Phase**: เพิ่มช่องทางสนทนาเสริมสำหรับผู้จัดทำหลักสูตร (ตอบคำถามเกี่ยวกับเกณฑ์มาตรฐาน + ให้คำแนะนำต่อเนื้อหาร่างที่พิมพ์/วางเข้ามาแบบทันที) แยกออกจาก flow ตรวจสอบหลักอย่างชัดเจน
**Feature ที่เกี่ยวข้อง**: [[../02-plan/feature-list|feature-list]] (09)

**Dependency**: ต้องรอ [[01-mvp|Phase 1]] เสร็จก่อน เนื่องจากช่องทางสนทนาต้องใช้ชุดเกณฑ์สถานะ active และกฎเกณฑ์สถานะ approved ชุดเดียวกันกับที่สร้างใน Phase 1 (อ้างอิงเหตุผลเดียวกับที่ระบุไว้ใน [[../02-plan/release-plan|release-plan]] หัวข้อ Dependency ของ Phase 3) แต่เป็นอิสระจาก [[02-next|Phase 2]] โดยสิ้นเชิง ไม่ได้ใช้ผลลัพธ์จากการตรวจสอบข้ามเล่มหรือตรวจสอบเนื้อหาจริง
