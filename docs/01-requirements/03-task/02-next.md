# Task Breakdown: Phase 2 - Next: ขยายความสามารถตรวจสอบ

**Phase อ้างอิง**: [[../02-plan/release-plan|release-plan]] (Phase 2)
**เป้าหมายของ Phase**: เพิ่มความลึก/ความกว้างของความสามารถตรวจสอบความสอดคล้อง ต่อยอดจาก Consistency Checking Engine เดิมที่สร้างใน Phase 1 โดยไม่ต้องเพิ่ม actor หรือ UI/journey ใหม่
**Feature ที่เกี่ยวข้อง**: [[../02-plan/feature-list|feature-list]] (04, 08)

**Dependency**: ต้องรอ [[01-mvp|Phase 1]] เสร็จสมบูรณ์ก่อน เพราะทุกงานในตารางด้านล่างต่อยอดจาก Consistency Checking Engine และหน้ารายงานผลตรวจสอบที่สร้างใน Phase 1 โดยตรง (อ้างอิงเหตุผลเดียวกับที่ระบุไว้ใน [[../02-plan/release-plan|release-plan]] หัวข้อ Dependency ของ Phase 2) ฟีเจอร์ 04 และ 08 เป็นอิสระต่อกันเอง ไม่มีลำดับก่อน-หลังบังคับระหว่างกัน
