รายการชุดเกณฑ์มาตรฐาน

สร้างชุดเกณฑ์ใหม่

ชุดเกณฑ์ที่มีสถานะ "เปิดใช้งาน (active)" จะปรากฏให้ผู้ใช้งานทั่วไปเลือกอ้างอิงตอนตรวจสอบเอกสารหรือสนทนากับแชทบอท ส่วนชุดที่ยังรอตรวจสอบ (pending) จะถูกซ่อนจากผู้ใช้งานทั่วไปจนกว่าจะอนุมัติกฎเกณฑ์ครบทุกข้อ — คลิกที่ชุดเกณฑ์สถานะรอตรวจสอบเพื่อไปตรวจสอบและอนุมัติกฎเกณฑ์
