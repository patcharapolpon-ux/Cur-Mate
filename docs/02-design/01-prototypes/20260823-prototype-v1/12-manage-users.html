จัดการผู้ใช้งานและบทบาท

รายชื่อผู้ใช้ทั้งหมดในระบบพร้อมบทบาทปัจจุบัน แอดมินสามารถเลื่อน/ปรับบทบาทของผู้ใช้คนอื่นได้ ยกเว้นบัญชีของตัวเอง เพื่อป้องกันไม่ให้ระบบเหลือแอดมิน 0 คนโดยไม่ตั้งใจ

การเปลี่ยนบทบาททุกครั้งต้องผ่านการตรวจสอบสิทธิ์ที่เซิร์ฟเวอร์ (backend) เสมอ ไม่ใช่แค่การควบคุมฝั่งหน้าจอ เพื่อป้องกันการเรียกใช้งานข้าม UI
