เพิ่มเมื่อ 01/09/2569

เพิ่มเมื่อ 15/08/2569

เพิ่มหลักสูตรใหม่

เพิ่มหลักสูตรภายใต้สำนักวิชาที่เลือกไว้ พร้อมแนบไฟล์หลักสูตรที่จะเสนอเข้าที่ประชุม — ไฟล์นี้เป็นไฟล์คนละชุดจากเล่ม มคอ.2 เดิมที่ใช้ในระบบตรวจสอบความสอดคล้อง
