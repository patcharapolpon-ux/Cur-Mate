จัดการหลักสูตรสำหรับแดชบอร์ดผู้บริหาร

หลักสูตรวิทยาศาสตรบัณฑิต สาขาวิทยาการคอมพิวเตอร์ (ปรับปรุง พ.ศ. 2569)

เพิ่มเมื่อ 01/09/2569 — ผ่านการตรวจสอบ

หลักสูตรวิทยาศาสตรบัณฑิต สาขาเทคโนโลยีสารสนเทศ (ปรับปรุง พ.ศ. 2568)

เพิ่มเมื่อ 15/08/2569 — ยังไม่ผ่านการตรวจสอบ

เพิ่มหลักสูตรใหม่

เพิ่มหลักสูตรภายใต้สำนักวิชาที่เลือกไว้ แล้วเลือกเล่ม มคอ.2 ที่มีอยู่แล้วในระบบมาผูกกับหลักสูตรนี้ — ไม่ต้องอัปโหลดไฟล์แยกชุดอีกต่อไป (FR ข้อ 5 ปรับปรุง 2026-09-13)

เล่มนี้ยังไม่เคยผ่านการตรวจสอบความสอดคล้อง

อนุญาตให้ผูกได้ตามปกติ (FR ข้อ 5.1) — สถานะบนแดชบอร์ดผู้บริหารจะแสดงเป็น "ยังไม่ผ่านการตรวจสอบ" อย่างชัดเจน ไม่นับเป็นผ่านโดยปริยาย
