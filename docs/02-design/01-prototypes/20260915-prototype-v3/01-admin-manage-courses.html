จัดการหลักสูตรสำหรับแดชบอร์ดผู้บริหาร

เพิ่มหลักสูตรใหม่

เลือกสำนักวิชาเพื่อดูรายชื่อหลักสูตรที่เพิ่มไว้แล้ว พร้อมเล่ม มคอ.2 ที่ผูกไว้และสถานะความสอดคล้อง — เวอร์ชันนี้ไม่มีการอัปโหลดไฟล์แยกชุดอีกต่อไป แอดมินผูกเล่ม มคอ.2 ที่มีอยู่แล้วในระบบเข้ากับหลักสูตรแทน (ดูปุ่ม "เพิ่มหลักสูตรใหม่")

หลักสูตรที่เพิ่มไว้แล้ว

ยังไม่มีหลักสูตรในสำนักวิชานี้

ยังไม่มีการเพิ่มหลักสูตรสำหรับสำนักวิชาที่เลือก กด "เพิ่มหลักสูตรใหม่" ด้านบนเพื่อเริ่มเพิ่มหลักสูตรแรกของสำนักวิชานี้
