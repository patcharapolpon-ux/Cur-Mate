จัดการชุดกรอบทักษะอ้างอิง

ชุดกรอบทักษะเป็นไม้บรรทัดของมิติ "ความสอดคล้องกับทักษะที่ตลาดต้องการ" บนแดชบอร์ดผู้บริหาร ใช้กลไกจัดการเดียวกับฐานความรู้เกณฑ์มาตรฐาน (อัปโหลด → AI สกัด → ตรวจสอบ/อนุมัติ) แต่เป็นคนละไม้บรรทัด

"ชุดกรอบทักษะ" เป็นคนละไม้บรรทัดกับ "ชุดเกณฑ์มาตรฐาน" — ชุดเกณฑ์มาตรฐานตอบว่า "หลักสูตรต้องมีอะไรตามกฎ" ส่วนชุดกรอบทักษะตอบว่า "ตลาดต้องการทักษะอะไร" นอกจากนี้ ชุดกรอบทักษะไม่มีสถานะ active/pending ระดับทั้งชุด (ต่างจากชุดเกณฑ์มาตรฐานที่ต้องอนุมัติครบทุกข้อก่อนทั้งชุดจะใช้งานได้) — ทักษะข้อใดที่อนุมัติแล้วถูกใช้เป็นไม้บรรทัดได้ทันทีทีละข้อ
