# API Spec

> เอกสารนี้เป็น **conceptual interface contract** สื่อสารว่าระบบมี operation อะไรบ้าง รับ-ส่งข้อมูลอะไร และเงื่อนไขก่อน-หลังทำงานเป็นอย่างไร **ไม่ผูกมัดกับ protocol/technical stack จริง** — ห้ามระบุ REST/GraphQL/gRPC, HTTP method, URL path, status code หรือรูปแบบ payload จริงในเอกสารนี้ รายละเอียดการ implement จริงให้ดูในเอกสารแยกอื่นใน [[index|02-technical]]

อ้างอิงจาก [[../../01-requirements/02-plan/feature-list|feature-list]], [[high-level-architecture|high-level-architecture]] และ [[database-schema|database-schema]] (entity ที่แต่ละ operation เกี่ยวข้อง)

## 1. ภาพรวม

เอกสารนี้ครอบคลุมทั้ง 3 spec ของโปรเจกต์ Curmate ณ ตอนนี้ (การตรวจสอบความสอดคล้องเอกสาร มคอ.2 [[../../01-requirements/01-spec/20260812-01-tqf2-consistency-check|20260812-01-tqf2-consistency-check]], ฐานความรู้เกณฑ์มาตรฐาน [[../../01-requirements/01-spec/20260823-02-criteria-knowledge-base|20260823-02-criteria-knowledge-base]] และแชทบอทให้คำแนะนำ [[../../01-requirements/01-spec/20260823-03-advisory-chatbot|20260823-03-advisory-chatbot]]) operation จัดกลุ่มตาม entity/ฟีเจอร์ที่เกี่ยวข้อง เรียงตามลำดับที่ปรากฏใน [[../../01-requirements/02-plan/feature-list|feature-list]] ทั้ง 9 ฟีเจอร์ ครอบคลุมทั้งฝั่งผู้จัดทำหลักสูตร (อัปโหลด/ยืนยันข้อมูลรายวิชา, เลือกชุดเกณฑ์, เริ่ม/ดูผลตรวจสอบความสอดคล้อง, สนทนากับแชทบอท) และฝั่งแอดมิน (จัดการฐานความรู้เกณฑ์มาตรฐาน, ตรวจสอบและอนุมัติกฎเกณฑ์)

## 2. รายการ Operation

### 2.1 เอกสารหลักสูตร

#### OP-01-01 อัปโหลดเอกสารหลักสูตร (มคอ.2)

- **คำอธิบาย**: ผู้จัดทำหลักสูตรอัปโหลดไฟล์ มคอ.2 (PDF/Word) ทีละ 1 ไฟล์เข้าระบบ
- **ผู้เรียกใช้ (Actor)**: ผู้จัดทำหลักสูตร
- **Entity ที่เกี่ยวข้อง**: เอกสารหลักสูตร
- **ข้อมูลนำเข้า (Input)**: ไฟล์เอกสาร (PDF หรือ Word) (บังคับ), ชื่อหลักสูตร (บังคับ)
- **ผลลัพธ์ (Output)**: สถานะรับไฟล์ (สำเร็จ/ถูกปฏิเสธ), ข้อมูลเอกสารหลักสูตรที่บันทึกแล้ว (ถ้าสำเร็จ)
- **Pre-condition**: ผู้เรียกมีบทบาทผู้จัดทำหลักสูตร
- **Post-condition/ผลลัพธ์ที่เกิดขึ้น**: ถ้าหลักสูตรเดียวกันเคยมีไฟล์อยู่แล้ว ไฟล์เดิมถูกแทนที่ทันที (ไม่เก็บ version history); เนื้อหาถูกส่งต่อเข้าสู่ขั้นตอนสกัดข้อมูลรายวิชาโดยอัตโนมัติ
- **กรณีข้อผิดพลาด/Exception**: ไฟล์ดึงข้อความไม่ได้ (เช่น สแกนภาพล้วน) → ปฏิเสธไฟล์ทันทีตั้งแต่ขั้นตอนนี้ พร้อมแจ้งเหตุผลให้ผู้ใช้แก้ไข/อัปโหลดใหม่ ไม่ผ่านเข้าสู่ขั้นตอนตรวจสอบ
- **อ้างอิง Requirement**: FR ข้อ 1 ของ [[../../01-requirements/01-spec/20260812-01-tqf2-consistency-check|20260812-01-tqf2-consistency-check]] / ฟีเจอร์ 01 ใน [[../../01-requirements/02-plan/feature-list|feature-list]]

### 2.2 ข้อมูลรายวิชาที่สกัดได้

#### OP-01-02 ดึงข้อมูลรายวิชาที่สกัดได้เพื่อตรวจสอบ

- **คำอธิบาย**: ดึงรายการจุดที่พบข้อมูลรายวิชาในเอกสารหลักสูตรหนึ่งเล่ม เพื่อให้ผู้จัดทำหลักสูตรตรวจสอบ/ยืนยัน
- **ผู้เรียกใช้ (Actor)**: ผู้จัดทำหลักสูตร
- **Entity ที่เกี่ยวข้อง**: ข้อมูลรายวิชาที่สกัดได้, จุดที่พบข้อมูลรายวิชาในเอกสาร
- **ข้อมูลนำเข้า (Input)**: เอกสารหลักสูตร (ตัวระบุ) (บังคับ)
- **ผลลัพธ์ (Output)**: รายการจุดที่พบข้อมูลรายวิชาในเอกสาร พร้อมค่าที่สกัดได้ ณ แต่ละจุดและสถานะยืนยันของแต่ละจุด
- **Pre-condition**: เอกสารหลักสูตรอ่านเนื้อหาได้สำเร็จแล้ว (ผ่าน OP-01-01)
- **Post-condition/ผลลัพธ์ที่เกิดขึ้น**: ไม่มีการเปลี่ยนแปลงข้อมูล (เป็นการอ่านอย่างเดียว)
- **กรณีข้อผิดพลาด/Exception**: ไม่พบเอกสารหลักสูตรตามที่ระบุ → แจ้งว่าไม่พบข้อมูล
- **อ้างอิง Requirement**: FR ข้อ 2 ของ [[../../01-requirements/01-spec/20260812-01-tqf2-consistency-check|20260812-01-tqf2-consistency-check]] / ฟีเจอร์ 01

#### OP-01-03 ยืนยัน/แก้ไขข้อมูลรายวิชาที่สกัดได้

- **คำอธิบาย**: ผู้จัดทำหลักสูตรยืนยันหรือแก้ไขค่าที่ระบบสกัดมา ณ จุดที่พบจุดหนึ่ง
- **ผู้เรียกใช้ (Actor)**: ผู้จัดทำหลักสูตร
- **Entity ที่เกี่ยวข้อง**: จุดที่พบข้อมูลรายวิชาในเอกสาร
- **ข้อมูลนำเข้า (Input)**: จุดที่พบ (ตัวระบุ) (บังคับ), ค่าที่ยืนยัน/แก้ไข (รหัสวิชา/ชื่อวิชา/หน่วยกิต/คำอธิบายรายวิชา) (บังคับ)
- **ผลลัพธ์ (Output)**: จุดที่พบซึ่งมีสถานะเปลี่ยนเป็น "ยืนยันแล้ว" พร้อมค่าล่าสุด
- **Pre-condition**: จุดที่พบนั้นอยู่ในสถานะ "รอยืนยัน"
- **Post-condition/ผลลัพธ์ที่เกิดขึ้น**: ค่าที่ยืนยันแล้วถูกนำไปปรับปรุงข้อมูลรายวิชาที่สกัดได้ระดับสรุปของรายวิชานั้น
- **กรณีข้อผิดพลาด/Exception**: ยังไม่กำหนด — รอข้อมูลเพิ่มเติมจากผู้ใช้ (เช่น กรณีค่าที่ยืนยันขัดแย้งกับจุดอื่นที่ยืนยันไปแล้วก่อนหน้า)
- **อ้างอิง Requirement**: FR ข้อ 2 ของ [[../../01-requirements/01-spec/20260812-01-tqf2-consistency-check|20260812-01-tqf2-consistency-check]] / ฟีเจอร์ 01

### 2.3 ชุดเกณฑ์ (ฝั่งผู้ใช้งานทั่วไป)

#### OP-02-01 ดึงรายชื่อชุดเกณฑ์ที่เปิดใช้งาน (active)

- **คำอธิบาย**: ดึงรายชื่อชุดเกณฑ์ทั้งหมดที่มีสถานะเปิดใช้งาน เพื่อให้ผู้ใช้งานทั่วไปเลือกก่อนเริ่มตรวจสอบเอกสารหรือเริ่มสนทนากับแชทบอท
- **ผู้เรียกใช้ (Actor)**: ผู้จัดทำหลักสูตร
- **Entity ที่เกี่ยวข้อง**: ชุดเกณฑ์
- **ข้อมูลนำเข้า (Input)**: -
- **ผลลัพธ์ (Output)**: รายชื่อชุดเกณฑ์สถานะ active พร้อม metadata (ชื่อ, ปี/ช่วงเวลาที่บังคับใช้, ระดับการศึกษา, ขอบเขต/สาขา)
- **Pre-condition**: -
- **Post-condition/ผลลัพธ์ที่เกิดขึ้น**: -
- **กรณีข้อผิดพลาด/Exception**: ไม่มีชุดเกณฑ์สถานะ active เลยในระบบ → แสดงรายการว่าง
- **อ้างอิง Requirement**: FR ข้อ 3 ของ [[../../01-requirements/01-spec/20260812-01-tqf2-consistency-check|20260812-01-tqf2-consistency-check]], FR ข้อ 2 ของ [[../../01-requirements/01-spec/20260823-02-criteria-knowledge-base|20260823-02-criteria-knowledge-base]] / ฟีเจอร์ 02

### 2.4 การตรวจสอบความสอดคล้อง

#### OP-03-01 เริ่มตรวจสอบความสอดคล้อง

- **คำอธิบาย**: เริ่มการตรวจสอบความสอดคล้องของเอกสารหลักสูตรหนึ่งเล่ม ครอบคลุมทั้งภายในเล่มเดียวกัน ข้ามเล่มกับเอกสารหลักสูตรอื่นในระบบ และเทียบเนื้อหาจริงกับกฎเกณฑ์ที่อนุมัติแล้วของชุดเกณฑ์ที่เลือก
- **ผู้เรียกใช้ (Actor)**: ผู้จัดทำหลักสูตร
- **Entity ที่เกี่ยวข้อง**: รอบตรวจสอบความสอดคล้อง, เอกสารหลักสูตร, ชุดเกณฑ์
- **ข้อมูลนำเข้า (Input)**: เอกสารหลักสูตร (ตัวระบุ) (บังคับ), รายชื่อชุดเกณฑ์ที่เลือก (อย่างน้อย 1 ชุด เลือกได้หลายชุด) (บังคับ)
- **ผลลัพธ์ (Output)**: รอบตรวจสอบความสอดคล้องที่สร้างขึ้นใหม่
- **Pre-condition**: ข้อมูลรายวิชาทุกจุดในเอกสารหลักสูตรนั้นต้องยืนยันแล้วทั้งหมด; ต้องเลือกชุดเกณฑ์อย่างน้อย 1 ชุด (บังคับ ไม่อนุญาตให้เริ่มตรวจสอบโดยไม่มีชุดเกณฑ์อ้างอิงเลย)
- **Post-condition/ผลลัพธ์ที่เกิดขึ้น**: ระบบตรวจสอบภายในเล่ม, ข้ามเล่ม, และเทียบเนื้อหากับเกณฑ์ที่อนุมัติแล้ว แล้วสร้างรายการจุดที่ไม่สอดคล้อง (Finding) ตามที่พบ ผูกกับรอบตรวจสอบนี้
- **กรณีข้อผิดพลาด/Exception**: ยังไม่ได้เลือกชุดเกณฑ์เลย → ปฏิเสธคำขอ; ยังมีข้อมูลรายวิชาบางจุดที่ยังไม่ยืนยัน → ปฏิเสธคำขอ
- **อ้างอิง Requirement**: FR ข้อ 3, FR ข้อ 4 ของ [[../../01-requirements/01-spec/20260812-01-tqf2-consistency-check|20260812-01-tqf2-consistency-check]], FR ข้อ 5 ของ [[../../01-requirements/01-spec/20260823-02-criteria-knowledge-base|20260823-02-criteria-knowledge-base]] / ฟีเจอร์ 02, 03, 04, 08

#### OP-03-02 ดึงรายงานผลตรวจสอบ

- **คำอธิบาย**: ดึงรายงานสรุปจุดที่ไม่สอดคล้องกันทั้งหมดของรอบตรวจสอบหนึ่งรอบ
- **ผู้เรียกใช้ (Actor)**: ผู้จัดทำหลักสูตร
- **Entity ที่เกี่ยวข้อง**: รอบตรวจสอบความสอดคล้อง, รายการจุดที่ไม่สอดคล้อง
- **ข้อมูลนำเข้า (Input)**: รอบตรวจสอบความสอดคล้อง (ตัวระบุ) (บังคับ)
- **ผลลัพธ์ (Output)**: รายการจุดที่ไม่สอดคล้องทั้งหมดของรอบนั้น พร้อมประเภท คำอธิบาย และตำแหน่ง/หน้าที่พบ
- **Pre-condition**: รอบตรวจสอบนั้นดำเนินการเสร็จสิ้นแล้ว
- **Post-condition/ผลลัพธ์ที่เกิดขึ้น**: -
- **กรณีข้อผิดพลาด/Exception**: รอบตรวจสอบยังดำเนินการไม่เสร็จ → แจ้งสถานะกำลังดำเนินการ
- **อ้างอิง Requirement**: FR ข้อ 5 ของ [[../../01-requirements/01-spec/20260812-01-tqf2-consistency-check|20260812-01-tqf2-consistency-check]] / ฟีเจอร์ 05

### 2.5 จัดการฐานความรู้เกณฑ์มาตรฐาน (แอดมิน)

#### OP-04-01 สร้างชุดเกณฑ์ใหม่

- **คำอธิบาย**: แอดมินสร้างและตั้งชื่อชุดเกณฑ์ใหม่ พร้อม metadata กำกับ
- **ผู้เรียกใช้ (Actor)**: แอดมิน
- **Entity ที่เกี่ยวข้อง**: ชุดเกณฑ์
- **ข้อมูลนำเข้า (Input)**: ชื่อชุดเกณฑ์ (บังคับ), ปี/ช่วงเวลาที่บังคับใช้ (ไม่บังคับ), ระดับการศึกษา (ไม่บังคับ), ขอบเขต/สาขา (ไม่บังคับ)
- **ผลลัพธ์ (Output)**: ชุดเกณฑ์ใหม่ที่สร้างขึ้น (สถานะเริ่มต้น: รอตรวจสอบ/pending)
- **Pre-condition**: ผู้เรียกมีบทบาทแอดมิน
- **Post-condition/ผลลัพธ์ที่เกิดขึ้น**: -
- **กรณีข้อผิดพลาด/Exception**: ไม่มีชื่อชุดเกณฑ์ → ปฏิเสธคำขอ
- **อ้างอิง Requirement**: FR ข้อ 1, FR ข้อ 2 ของ [[../../01-requirements/01-spec/20260823-02-criteria-knowledge-base|20260823-02-criteria-knowledge-base]] / ฟีเจอร์ 06

#### OP-04-02 อัปโหลดเอกสารเกณฑ์มาตรฐานเข้าชุดเกณฑ์

- **คำอธิบาย**: แอดมินอัปโหลดเอกสารเกณฑ์มาตรฐาน (PDF/Word) เข้าชุดเกณฑ์ที่มีอยู่แล้ว
- **ผู้เรียกใช้ (Actor)**: แอดมิน
- **Entity ที่เกี่ยวข้อง**: เอกสารเกณฑ์มาตรฐาน, กฎเกณฑ์, ชุดเกณฑ์
- **ข้อมูลนำเข้า (Input)**: ชุดเกณฑ์ (ตัวระบุ) (บังคับ), ไฟล์เอกสาร (PDF หรือ Word) (บังคับ)
- **ผลลัพธ์ (Output)**: เอกสารเกณฑ์มาตรฐานที่บันทึกแล้ว, รายการกฎเกณฑ์ใหม่ที่ AI สกัดได้อัตโนมัติ (สถานะเริ่มต้น: รอตรวจสอบ/pending)
- **Pre-condition**: ผู้เรียกมีบทบาทแอดมิน; ชุดเกณฑ์ที่ระบุมีอยู่จริง
- **Post-condition/ผลลัพธ์ที่เกิดขึ้น**: กฎเกณฑ์ใหม่ถูกส่งเข้าสถานะรอตรวจสอบเสมอ ไม่กระทบกฎเกณฑ์เดิมของชุดเกณฑ์นั้นที่อนุมัติแล้ว แม้ชุดเกณฑ์นั้นจะมีสถานะ active อยู่ก่อนแล้วก็ตาม (ชุดเกณฑ์ไม่ถูกเปลี่ยนกลับเป็น pending)
- **กรณีข้อผิดพลาด/Exception**: ไฟล์ดึงข้อความไม่ได้ → แจ้งเตือนผู้ใช้ (สมมติฐาน: ใช้กติกาเดียวกับ OP-01-01)
- **อ้างอิง Requirement**: FR ข้อ 3 ของ [[../../01-requirements/01-spec/20260823-02-criteria-knowledge-base|20260823-02-criteria-knowledge-base]] / ฟีเจอร์ 06

### 2.6 ตรวจสอบและอนุมัติกฎเกณฑ์ (แอดมิน)

#### OP-05-01 ดึงรายการกฎเกณฑ์ที่รอตรวจสอบของชุดเกณฑ์

- **คำอธิบาย**: ดึงรายการกฎเกณฑ์ทั้งหมดที่ยังอยู่ในสถานะรอตรวจสอบของชุดเกณฑ์หนึ่งชุด เพื่อให้แอดมินตรวจสอบ
- **ผู้เรียกใช้ (Actor)**: แอดมิน
- **Entity ที่เกี่ยวข้อง**: กฎเกณฑ์, ชุดเกณฑ์
- **ข้อมูลนำเข้า (Input)**: ชุดเกณฑ์ (ตัวระบุ) (บังคับ)
- **ผลลัพธ์ (Output)**: รายการกฎเกณฑ์สถานะรอตรวจสอบ (pending) ของชุดเกณฑ์นั้น
- **Pre-condition**: ผู้เรียกมีบทบาทแอดมิน
- **Post-condition/ผลลัพธ์ที่เกิดขึ้น**: -
- **กรณีข้อผิดพลาด/Exception**: -
- **อ้างอิง Requirement**: FR ข้อ 4 ของ [[../../01-requirements/01-spec/20260823-02-criteria-knowledge-base|20260823-02-criteria-knowledge-base]] / ฟีเจอร์ 07

#### OP-05-02 แก้ไขเนื้อหากฎเกณฑ์ที่ AI สกัดมา

- **คำอธิบาย**: แอดมินแก้ไขเนื้อหาของกฎเกณฑ์ก่อนอนุมัติ
- **ผู้เรียกใช้ (Actor)**: แอดมิน
- **Entity ที่เกี่ยวข้อง**: กฎเกณฑ์
- **ข้อมูลนำเข้า (Input)**: กฎเกณฑ์ (ตัวระบุ) (บังคับ), เนื้อหากฎเกณฑ์ที่แก้ไข (บังคับ)
- **ผลลัพธ์ (Output)**: กฎเกณฑ์ที่มีเนื้อหาอัปเดตแล้ว (สถานะยังคงเป็นรอตรวจสอบ)
- **Pre-condition**: กฎเกณฑ์นั้นอยู่ในสถานะรอตรวจสอบ
- **Post-condition/ผลลัพธ์ที่เกิดขึ้น**: -
- **กรณีข้อผิดพลาด/Exception**: กฎเกณฑ์นั้นอนุมัติไปแล้ว → ปฏิเสธการแก้ไข
- **อ้างอิง Requirement**: FR ข้อ 4 ของ [[../../01-requirements/01-spec/20260823-02-criteria-knowledge-base|20260823-02-criteria-knowledge-base]] / ฟีเจอร์ 07

#### OP-05-03 อนุมัติกฎเกณฑ์ (รายข้อหรือ bulk)

- **คำอธิบาย**: แอดมินอนุมัติกฎเกณฑ์หนึ่งข้อ หรืออนุมัติหลายข้อพร้อมกัน (bulk approve)
- **ผู้เรียกใช้ (Actor)**: แอดมิน
- **Entity ที่เกี่ยวข้อง**: กฎเกณฑ์, ชุดเกณฑ์
- **ข้อมูลนำเข้า (Input)**: รายการกฎเกณฑ์ที่จะอนุมัติ (ตัวระบุเดียวหรือหลายตัวระบุ) (บังคับ)
- **ผลลัพธ์ (Output)**: กฎเกณฑ์ที่อนุมัติแล้ว (สถานะเปลี่ยนเป็น approved) พร้อมผู้อนุมัติ
- **Pre-condition**: กฎเกณฑ์แต่ละข้อที่จะอนุมัติต้องอยู่ในสถานะรอตรวจสอบ
- **Post-condition/ผลลัพธ์ที่เกิดขึ้น**: ถ้ากฎเกณฑ์ทั้งหมดในชุดเกณฑ์เดียวกันผ่านการอนุมัติครบแล้ว ชุดเกณฑ์นั้นเปลี่ยนสถานะเป็นเปิดใช้งาน (active) โดยอัตโนมัติ (ทำให้ปรากฏในผลลัพธ์ของ OP-02-01 และใช้งานได้ใน OP-03-01/OP-06-01/OP-06-02/OP-06-03)
- **กรณีข้อผิดพลาด/Exception**: กฎเกณฑ์บางข้อที่ระบุอนุมัติไปแล้วก่อนหน้า → ยังไม่กำหนดว่าควรข้ามหรือแจ้งข้อผิดพลาด (รอข้อมูลเพิ่มเติมจากผู้ใช้)
- **อ้างอิง Requirement**: FR ข้อ 4 ของ [[../../01-requirements/01-spec/20260823-02-criteria-knowledge-base|20260823-02-criteria-knowledge-base]] / ฟีเจอร์ 07

### 2.7 แชทบอทให้คำแนะนำ (Advisory Chatbot)

#### OP-06-01 เริ่มสนทนากับแชทบอท (เลือกชุดเกณฑ์)

- **คำอธิบาย**: ผู้จัดทำหลักสูตรเริ่มช่องทางสนทนากับแชทบอทให้คำแนะนำ โดยต้องเลือกชุดเกณฑ์ที่จะอ้างอิงก่อนเสมอ
- **ผู้เรียกใช้ (Actor)**: ผู้จัดทำหลักสูตร
- **Entity ที่เกี่ยวข้อง**: ชุดเกณฑ์ (อ้างอิงอย่างเดียว — ไม่มี entity การสนทนาในสคีมา เนื่องจากไม่มีการบันทึกถาวร)
- **ข้อมูลนำเข้า (Input)**: รายชื่อชุดเกณฑ์ที่เลือก (อย่างน้อย 1 ชุด เฉพาะสถานะ active) (บังคับ)
- **ผลลัพธ์ (Output)**: ช่องทางสนทนาที่พร้อมใช้งาน ยึดชุดเกณฑ์ที่เลือกไว้ตลอดช่วงสนทนานั้น
- **Pre-condition**: มีชุดเกณฑ์สถานะ active ให้เลือกอย่างน้อย 1 ชุด
- **Post-condition/ผลลัพธ์ที่เกิดขึ้น**: -
- **กรณีข้อผิดพลาด/Exception**: ยังไม่ได้เลือกชุดเกณฑ์เลย → ปฏิเสธการเริ่มสนทนา
- **อ้างอิง Requirement**: FR ข้อ 2 ของ [[../../01-requirements/01-spec/20260823-03-advisory-chatbot|20260823-03-advisory-chatbot]] / ฟีเจอร์ 02, 09

#### OP-06-02 ถามคำถามทั่วไปเกี่ยวกับเกณฑ์มาตรฐาน (Q&A)

- **คำอธิบาย**: ผู้จัดทำหลักสูตรถามคำถามเกี่ยวกับเนื้อหาเกณฑ์มาตรฐานในฐานความรู้ของชุดเกณฑ์ที่เลือกไว้
- **ผู้เรียกใช้ (Actor)**: ผู้จัดทำหลักสูตร
- **Entity ที่เกี่ยวข้อง**: กฎเกณฑ์ (เฉพาะสถานะ approved ของชุดเกณฑ์ที่เลือกในสนทนานี้)
- **ข้อมูลนำเข้า (Input)**: คำถามเป็นข้อความ (บังคับ)
- **ผลลัพธ์ (Output)**: คำตอบที่อ้างอิงเฉพาะเนื้อหาในฐานความรู้ของชุดเกณฑ์ที่เลือกไว้เท่านั้น
- **Pre-condition**: อยู่ในสถานะสนทนาที่เลือกชุดเกณฑ์แล้ว (ผ่าน OP-06-01)
- **Post-condition/ผลลัพธ์ที่เกิดขึ้น**: ไม่มีการบันทึกเนื้อหาคำถาม/คำตอบนี้เป็นส่วนหนึ่งของฐานความรู้ถาวร
- **กรณีข้อผิดพลาด/Exception**: คำถามอยู่นอกขอบเขตของฐานความรู้ที่เลือกไว้ → ยังไม่กำหนด — รอข้อมูลเพิ่มเติมจากผู้ใช้ (spec ระบุเป็นคำถามเปิด)
- **อ้างอิง Requirement**: FR ข้อ 1(ก), FR ข้อ 3 ของ [[../../01-requirements/01-spec/20260823-03-advisory-chatbot|20260823-03-advisory-chatbot]], FR ข้อ 6 ของ [[../../01-requirements/01-spec/20260823-02-criteria-knowledge-base|20260823-02-criteria-knowledge-base]] / ฟีเจอร์ 09

#### OP-06-03 ส่งเนื้อหาร่างบางส่วนเพื่อขอคำแนะนำแบบทันที

- **คำอธิบาย**: ผู้จัดทำหลักสูตรพิมพ์/วางเนื้อหาร่างบางส่วนที่กำลังเขียนอยู่ เพื่อขอคำแนะนำทันทีว่าสอดคล้องกับเกณฑ์มาตรฐานหรือไม่
- **ผู้เรียกใช้ (Actor)**: ผู้จัดทำหลักสูตร
- **Entity ที่เกี่ยวข้อง**: กฎเกณฑ์ (เฉพาะสถานะ approved ของชุดเกณฑ์ที่เลือกในสนทนานี้)
- **ข้อมูลนำเข้า (Input)**: เนื้อหาร่างบางส่วนที่พิมพ์/วางเข้ามา (ยังไม่ใช่ไฟล์เต็มเล่ม) (บังคับ)
- **ผลลัพธ์ (Output)**: คำแนะนำ/ชี้จุดที่อาจไม่สอดคล้องกับเกณฑ์มาตรฐานแบบทันที (รูปแบบผลลัพธ์แน่ชัด เช่น freeform หรือ list ยังไม่กำหนด)
- **Pre-condition**: อยู่ในสถานะสนทนาที่เลือกชุดเกณฑ์แล้ว (ผ่าน OP-06-01)
- **Post-condition/ผลลัพธ์ที่เกิดขึ้น**: ไม่บันทึกเนื้อหาร่างที่ส่งเข้ามาเป็นส่วนหนึ่งของฐานความรู้ถาวร ไม่นำไปใช้อ้างอิงต่อในสนทนาของผู้ใช้คนอื่นหรือครั้งอื่น; ผลลัพธ์นี้เป็นเพียงคำแนะนำเบื้องต้น ไม่ใช่ผลตรวจสอบอย่างเป็นทางการ (ไม่ทดแทน OP-03-01)
- **กรณีข้อผิดพลาด/Exception**: -
- **อ้างอิง Requirement**: FR ข้อ 1(ข) ของ [[../../01-requirements/01-spec/20260823-03-advisory-chatbot|20260823-03-advisory-chatbot]] / ฟีเจอร์ 09

- OP-01-03 (ยืนยัน/แก้ไขข้อมูลรายวิชาที่สกัดได้): กรณีข้อผิดพลาดเมื่อค่าที่ยืนยันขัดแย้งกับจุดอื่นที่ยืนยันไปแล้วก่อนหน้ายังไม่กำหนด รอข้อมูลเพิ่มเติมจากผู้ใช้
