## สมมติฐาน / ข้อจำกัดของต้นแบบที่ใช้ในการออกแบบ Test Case นี้

- **TC-13-001**: หน้าต้นแบบ `12-manage-users.html` จำลองการเปลี่ยนบทบาทด้วย JavaScript ฝั่งหน้าจอเท่านั้น (เปลี่ยนข้อความ chip ทันทีเมื่อเลือกค่าใน dropdown) ยังไม่ได้เชื่อมต่อการตรวจสอบสิทธิ์ที่ backend จริงตามที่ NFR ของ spec ต้นทางกำหนด (ระบุไว้ใน dev-note ของไฟล์ต้นแบบเอง) จึงทดสอบได้เฉพาะพฤติกรรมที่มองเห็นบนหน้าจอ (UI-level) ในรอบนี้ ส่วนการตรวจสอบสิทธิ์และการบันทึกจริงที่ backend ต้องกลับมาเพิ่ม test case ทดสอบซ้ำเมื่อมี [[../../../02-design/02-technical/index|02-technical]] จริง
- **TC-13-003**: หน้าต้นแบบ `12-manage-users.html` ปัจจุบันเป็นเพียงไฟล์ static HTML ที่เปิดดูได้โดยตรงจากทุกบัญชี ยังไม่มีกลไกจำกัดสิทธิ์ตามบทบาท (auth guard/route protection) ในระดับต้นแบบ ขั้นตอน/ผลลัพธ์ที่คาดหวังของ test case นี้จึงออกแบบอ้างอิงจาก AC-13-03 และ NFR ของ [[../../../01-requirements/01-spec/20260912-05-authentication-user-roles|authentication-user-roles]] โดยตรง ยังทดสอบจริงไม่ได้จนกว่าจะมีการเชื่อมต่อ backend/route protection จริง ต้องกลับมาทดสอบซ้ำเมื่อมี [[../../../02-design/02-technical/index|02-technical]] ที่เกี่ยวข้อง
